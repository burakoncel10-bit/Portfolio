Text-to-SQL Agent with Evaluation Harness

Personal project, 2026

Ask a retail database a question in plain English and get the answer back together with the SQL that produced it. The agent reads the live schema, generates a query, refuses anything that is not read-only, and runs it. The interesting part is the evaluation: 20 reference questions across eight query types, scored on whether the returned rows match, not on how the SQL is spelled.

Python · SQLite · Gemini · Streamlit

Erasmus Guide — AI Study Agent

Personal project, ongoing

A study agent for the Erasmus English exam that I use for my own preparation. It began as a Claude Code skill, where everything that mattered was an instruction the model was asked to follow. Rebuilding it as an application turned those instructions into guarantees: essay scores come back through a fixed JSON schema, so reviews stay comparable week to week; every result is stored, so the study planner can read past scores and adapt; and each mode loads only the reference files it needs, about a third of the knowledge base for essay scoring.

Python · Streamlit · SQLite · Gemini
